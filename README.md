## 🚀 Applied Project — SmartBranch 360

**SmartBranch 360** is a simulated branch-office network designed using Cisco Packet Tracer.

The project progresses through multiple topology stages:

1. Basic LAN
2. VLAN and Inter-VLAN Routing
3. DHCP and DNS
4. Final integrated branch-office network

The final topology incorporates:

- VLAN 10 and VLAN 20
- Inter-VLAN Routing
- DHCP
- DNS
- Static Routing
- ACLs
- NAT
- Wireless Connectivity

## 🛠️ Fault Diagnosis Tool

A companion **Python-based fault-diagnosis tool** was developed to support network troubleshooting.

The tool matches typed network symptoms against a documented set of **30 network fault cases** and suggests possible causes and fixes.
